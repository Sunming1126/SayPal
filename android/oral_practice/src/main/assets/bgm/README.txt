背景音乐（BGM）目录说明
============================

这里是课程听力输入环节（第一部分）的 BGM 候选目录。

你可以把 mp3 / m4a / wav / ogg / aac 文件放到这里，它们会被打包进 APK。
应用启动后，在"设置 -> 背景音乐"里就能看到并选择。

如果不想重新打包 APK 就换 BGM，把文件放到以下目录即可（同样被自动识别）：

  /Android/data/com.example.myapplication/files/bgm/

Tips:
- 建议使用 30s~2min 的循环友好片段（会被自动 looping 播放）。
- 文件名即为应用里显示的名字（不含扩展名）。
- 默认音量较低，可在设置里调整；也可以一键关闭 BGM。
